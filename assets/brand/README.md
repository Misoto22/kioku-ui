# Kioku UI brand assets

The README hero is a paired raster banner system. Both files use the same
layout, wordmark, and seal mark; only their surface and contrast change.

| Asset            | Intended use       | Palette                                       |
| ---------------- | ------------------ | --------------------------------------------- |
| `hero-light.png` | GitHub light theme | Rice paper · charcoal ink · restrained indigo |
| `hero-dark.png`  | GitHub dark theme  | Sumi black · warm paper · restrained indigo   |

## Visual language

The mark is an abstract seal: a squared construction grid, circular measure,
and three indigo forms. The wordmark is Mincho-inspired Latin serif lettering;
the descriptor is monospaced utility type. The exact banner copy is `KIOKU UI`
and `REACT COMPONENT SYSTEM`.

The hero is served through the root README's `<picture>` element. Keep both
files at 1600 × 500 px and change them as a matched pair.
